# AirPods Max — FORM—LAB

Интерактивная концепция лендинга на React, Vite и Three.js. Сборка сохраняет scroll-driven анимацию и исходную модель AirPods Max.

## Запуск

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

Модель находится в `public/`; лицензия автора DJM — CC BY 4.0. Фоновый GradientText основан на компоненте React Bits.
